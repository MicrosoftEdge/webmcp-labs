Event Search - Declarative WebMCP Demo

Three variations of the same form, each demonstrating a different declarative WebMCP capability. Switch tabs to compare.

The agent fills in the form fields, but the user must review and click Search to submit. No toolautosubmit attribute is present.

manual-review.html

Adding toolautosubmit lets the agent fill and submit the form automatically, no manual click required.

auto-submit.html

With a submit event listener you can intercept agent submissions, perform your own logic (e.g. a fetch), and return a custom value to the agent via event.respondWith().

custom-response.html
